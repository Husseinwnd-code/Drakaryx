# DRAKARYX Website

## Run the corrected version locally

Open this folder in VS Code, then run:

```bash
npm install
npm run dev
```

Open the local address shown by Vite (usually `http://localhost:5173`).
Do not open an old `dist/index.html` file directly.

## Build for production

```bash
npm run build
```

The new production files will be generated in `dist/`.
